# Preliminary execution snapshot — 2026-09-25

These archived CSV/Markdown files were present in the user-provided
September 25 RAR file. They are **not** the final evaluation data
described in the October 2026 ADHuman manuscript.

- `results/raw_runs.csv`: 80 recorded executions; 76 with `status=ok`,
  four with `status=error`.
- `results_aim/raw_aim_runs.csv`: 8 recorded executions with `status=ok`.
- `results/analysis/*`: summary reports generated from the available
  classifier execution subset.

The websites in `adhuman_experiment_preliminary/sites.csv` are
open-data, university/public, and international organization websites,
not the later high-traffic website sample. Do not use these archived
CSV files to substantiate the paper's 118/101/37 counts.
