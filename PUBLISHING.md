# Publishing this source to GitHub

**The ZIP supplied with this document is local only.** It has not
been pushed to any external repository.

If you have an existing private or public GitHub repository and
permission to edit it:

1. Clone the *source* GitHub repository to your machine.
2. Back up its current code and identify any files not present in the
   September snapshot that you still need.
3. Copy the contents of the prepared ZIP into the repository, taking
   care not to overwrite a newer October version.
4. Remove obsolete prototype files only after comparing them.
5. Run `git status`, then `git add -A`, `git commit`, `git push`.
6. Inspect the public file tree and confirm your anonymous mirror
   reflects the updated source.

**Before an anonymous paper submission:** inspect file contents,
commit history, account links and downloadable artifacts for author
names, emails, usernames, paths or other identifiers.

This source does **not** include the October high-traffic-site
dataset, so do not declare the full paper reproducible until that
dataset and matching runner are provided.
